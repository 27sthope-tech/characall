# CharaCall [デスクトップ切り抜きマスコット版]

**「四角いウィンドウ枠なし！Y2Kクリスタルガラケーの形だけをデスクトップにくり抜いて浮遊・常駐する推しキャラパートナー」**

---

## 📱 アプリの特徴（新ガラケー切り抜き透明化）
四角いブラウザウィンドウや矩形フレームを完全に撤廃し、**「透明クリスタル樹脂バンパーをまとったY2Kストレートガラケー」**がWindows/Macのデスクトップ壁紙の上に浮かび上がります。

1. **ガラケーの形だけを透明切り抜き**:
   - 背景は100%透過。四角いブラウザ枠、タイトルバー、四角い余白背景は一切ありません。
   - アンテナ、クリスタル樹脂バンパー、メタリックボディ、ドロップシャドウだけがデスクトップ上に美しく配置されます。
   - 企業のロゴ等の余計な文字はなく、洗練されたオリジナル外観に仕上げられています。
2. **正確な液晶ディスプレイ配置（361px × 425px）**:
   - 新しいガラケーの黒色ガラスベゼル枠と内蔵液晶画面が1ピクセルの狂いもなく完全に揃っており、時計やステータスバー、下部ドック（Menu / 決定 / メール）が画面枠内にぴったり収まります。
3. **実機写真クオリティの本体7色カラーバリエーション**:
   - 単なるCSS色調変更ではなく、実際の3Dレンダリング質感（メタリックな輝きとクリスタル樹脂の反射）を持つ7色の専用カットアウト画像を内蔵。
   - 画面内の「Menu」→「📱色」からいつでも即座に切り替え可能（次回起動時も状態を自動保持）。
   - **さくらピンク**（クリスタル・メタリックピンク）
   - **ソーダブルー**（アイシー・アクアブルー）
   - **メロンミント**（爽快パールグリーン）
   - **ラベンダーパープル**（エレガント・スミレ色）
   - **シャンパンゴールド**（高級感あふれるゴールド）
   - **コーラルピーチ**（温かいアプリコットオレンジ）
   - **チタニウムブラック**（シックなメタリックチャコール）
4. **コマンドプロンプトが出ないサイレント起動**:
   - 起動時に黒いコンソール（cmd.exe）ウィンドウが一切表示されず、ガラケー本体だけが静かにデスクトップに現れます。
5. **マウスでつかんでどこでもドラッグ移動**:
   - ガラケーの本体ボディをクリックしたままドラッグするだけで、画面上の好きな位置へ自由に動かせます。
6. **最前面固定（Pin）対応**:
   - ガラケー左肩の「📌」ボタンで、作業中も他のウィンドウの上に常にガラケーを表示させておけます。
7. **物理キーパッド連動**:
   - 中央の丸型十字キー（決定キー）：通話応答・メニュー呼び出し
   - ✉（メールキー）：トーク・チャット画面
   - 📖（電話帳キー）：メニュー画面
   - 左スラッシュキー（通話開始）：通話・チャット
   - 右スラッシュキー（切断・電源）：待受復帰・電源メニュー
8. **完全無音＆光とバイブ着信**:
   - 音声は鳴らさず、着信時はガラケー本体がカタカタと微振動し、左上LEDが七色に点滅。
9. **Menu内にすべての設定を統合**:
   - 待受の散らかりをなくし、液晶画面内の「Menu」からキャラ設定、自由プロンプト入力、背景設定（画像アップロード対応）、本体7色カラー、着信頻度を設定可能。

## 🚀 起動方法

### 【Windows 1クリック起動（黒い画面が出ない完全サイレント起動）】
フォルダ内の **`CharaCall.vbs`** または **`run-app.vbs`** （あるいは **`run-app.bat`**）をダブルクリック！
コマンドプロンプトの黒いウィンドウを一切出さずに、デスクトップ上にガラケーが直接現れます。

※ PowerShellから起動する場合：
```powershell
.\run-app.ps1
```

### 【ブラウザでのプレビュー確認】
`demo.html` または `index.html` を直接ダブルクリックしてブラウザで開くことも可能です（ブラウザで開いた場合はプレビュー用背景が自動表示されます）。

---

## 🎮 主な操作
- **本体の移動**: ガラケーのボディ部分をドラッグ
- **液晶画面操作**: 待受時計、作業時間表示、Menu（設定）、メール（トーク）
- **キー操作**: 十字キー中央（決定）、✉（メール）、📖（メニュー）、通話/切断キー
